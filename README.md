# JudyTik Downloads

Windows installers and automatic-update files for JudyTik.

Download the latest Windows x64 installer from [Releases](https://github.com/alongkon2103/JudyTik-Releases/releases). Install once, then check future versions from **Settings → Program and updates** inside JudyTik. Installation is per user. Saved account data is kept separately from the program files.

The initial builds are unsigned test releases. Windows may display an unknown-publisher warning.

This public repository contains release information and installers only. Application source is maintained privately.
